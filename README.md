# Aarón Revelo Jiménez — Portfolio

Portfolio personal: desarrollo web, tecnología y atención al cliente. Madrid.

Web estática (HTML, CSS y JavaScript sin dependencias) con un diseño inspirado en Apple:
tipografía del sistema, barra de navegación translúcida, cuadrícula tipo *bento*,
modo oscuro automático y soporte de `prefers-reduced-motion`.

## Ver en local

Abre `index.html` en el navegador.

## Publicación

Se publica con GitHub Pages desde la rama `main`.
